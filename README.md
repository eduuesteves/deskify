## ✨ Funcionalidades

- **Gestão de Usuários:** Cadastro de clientes e técnicos de suporte.
- **Controle de Empresas:** Vinculação de chamados por empresa cliente.
- **Tickets de Suporte:** Abertura, atualização de status e definição de prioridades.
- **Interface Moderna:** Front-end responsivo e focado na experiência do usuário.

## 📂 Estrutura do Projeto


| Pasta | Descrição | Stack Principal |
|---|---|---|
| 🖥️ `/server` | API RESTful e regras de negócio | Node.js, Express, Prisma ORM |
| 🎨 `/layout` | Interface do usuário (SPA) | React, Vite, SCSS, Axios |
